# Exercise & Injury Risk Analysis Dashboard

An interactive **Tableau dashboard** exploring the relationship between physical activity, training intensity, recovery, and injury risk. The project aims to help recreational exercisers better understand how to balance **activity, training effort, and recovery** for optimal fitness outcomes.

🔗 **[View Interactive Dashboard on Tableau Public](https://public.tableau.com/app/profile/zi.ting.mow/viz/FIT3179DataVisualization1_17885252131560/Dashboard?publish=yes)**

## 🎯 Project Objective

Exercising more or training harder does not always lead to better results. This project explores patterns between:

* Physical activity and workout performance
* Training intensity and training load
* Recovery and sleep
* Fatigue and injury risk

The dashboard allows users to interactively explore these relationships and identify patterns that may help support a more balanced approach to exercise.

> **Note:** The analysis focuses on observed patterns and associations rather than proving causal relationships.

## 📊 Datasets

The project combines three fitness and sports-related datasets:

1. **User Activity Dataset** – Daily activity information such as steps, active minutes, distance, calories burned, sleep, and heart rate.
2. **Health & Fitness Tracker Dataset** – Health and activity measures including age, gender, BMI, activity levels, sleep, hydration, and heart rate.
3. **Multimodal Sports Injury Dataset** – Training, physiological, biomechanical, and injury-related measures from athletes.

The datasets were used together at the **storytelling/analysis level** to explore related fitness and injury patterns. They do not represent the same individuals.

## 🧹 Data Processing

The data preparation process included:

* Reviewing and selecting relevant attributes
* Cleaning and converting numerical variables
* Handling heart-rate data
* Reshaping quantitative measures into a consistent format
* Normalising variables with different scales for comparison
* Combining relevant information for visual analysis

## 📈 Visualisations

The dashboard contains **13 visualisations**, including:

* Lollipop Chart
* Histogram
* Stacked Bar Chart
* Bubble Chart
* Area Chart
* Line Chart
* Box Plot
* Radar Chart
* Heat Map
* Dumbbell Chart
* Scatter Plot

These visualisations examine different aspects of activity, workout intensity, recovery, fatigue, training load, and injury risk.

## 🖱️ Interactivity

Interactive features allow users to:

* Filter by workout/activity type
* Explore different activity levels
* Compare training and recovery patterns
* Interact with visualisations to identify specific trends and patterns

## 🛠️ Tools & Technologies

* **Tableau** – Dashboard development and data visualisation
* **Data Preparation** – Data cleaning, transformation and normalisation
* **Tableau Public** – Dashboard publication

## 📌 Key Takeaway

The dashboard highlights the importance of considering **training effort together with recovery**, rather than focusing only on exercising more or harder. It provides an interactive way for recreational exercisers to explore activity and recovery patterns and better understand potential injury-risk patterns.
